# Terry — офлайн голосовой помощник для Windows

Лёгкий и полностью бесплатный голосовой помощник в системном трее Windows (без окна консоли и без интернета). Откликается на имя **«Терри»**, автоматически приглушает звук на 50%, понимает цепочки команд подряд и управляет треками, точной громкостью Windows (`0–100%`) и таймером выключения ПК.

## Возможности

- **100% офлайн и бесплатно** — компактная русская модель `Vosk` (`vosk-model-small-ru-0.22`) + порог тишины (VAD), почти 0% CPU в простое.
- **Приглушение звука на 50% и диалог без повтора имени:**
  - При слове **«Терри»** системная громкость плавно снижается наполовину на **5 секунд**, а иконка в трее становится жёлтой.
  - Внутри окна можно давать несколько команд подряд (например: *«Терри, тише»* → *«тише»* → *«дальше»*).
  - После каждой принятой команды окно и приглушённый звук продлеваются ещё на **3 секунды**.
  - По окончании паузы громкость плавно возвращается к **новому итоговому уровню**.
- **Точная громкость Windows (`0–100%`)** через нативный Core Audio COM API (`ctypes`, без сторонних аудиобиблиотек).
- **Таймер выключения ПК** с распознаванием русских числительных, минут и часов + голосовая отмена.
- **Системный трей:** выбор микрофона, пауза прослушивания, автоперезагрузка `commands.json`, автозапуск с Windows.

## Быстрая установка (Windows)

1. Установите Python 3.11+ (с добавлением в `PATH`).
2. Клонируйте репозиторий или скачайте ZIP и распакуйте.
3. Запустите в PowerShell:
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\setup.ps1
   ```
   Скрипт сам создаст `.venv`, установит зависимости из `requirements.txt` и скачает русскую офлайн-модель `vosk-model-small-ru-0.22` (~45 МБ).
4. Запустите **Терри** двойным кликом по `Start Voice Media.vbs` — в трее появится синяя иконка микрофона.

## Голосовые команды

- **Вперёд:** «Терри, дальше / некст / скип / следующий трек / вперёд».
- **Назад:** «Терри, назад / предыдущий трек / верни трек / обратно».
- **Сначала:** «Терри, сначала / заново / повтори трек».
- **Стоп / Продолжи:** «Терри, стоп / пауза / продолжи / плей».
- **Громче / Тише:** «Терри, громче», «Терри, тише», «Терри, громче на 20», «Терри, тише на 15», «Терри, выключи звук».
- **Точная громкость (0–100%):** «Терри, громкость 45», «Терри, измени громкость на 70», «Терри, звук на 20 процентов», «Терри, громкость на максимум / половину / ноль».
- **Таймер сна (выключение ПК):** «Терри, выключи комп через 30 минут», «… через полчаса», «… через полтора часа», «… через час двадцать».
- **Отмена выключения:** «Терри, отмена выключения / отмени выключение / не выключай комп / отмена таймера».

## Индикация в трее

- **Синяя** — ждёт имя «Терри».
- **Жёлтая** — активное окно команд (звук приглушён на 50%).
- **Зелёная вспышка** — команда выполнена.
- **Серая** — прослушивание на паузе.

## Структура проекта

- `voice_media.py` — фоновый сервис, захват микрофона, VAD, Vosk и иконка в трее.
- `matcher.py` — распознавание имени «Терри», многошагового окна (5 с / +3 с) и команд.
- `ru_numbers.py` — парсер русских числительных и длительностей (минуты, часы, *полчаса*, *полтора часа*).
- `media_keys.py` — нативные Win32 медиа-клавиши, Windows Core Audio громкость (`0–100%`), таймер выключения и автозапуск.
- `commands.json` — все фразы и настройки (подхватываются автоматически без перезапуска).
- `Start Voice Media.vbs` — тихий запуск в трей без окна консоли.
- `setup.ps1` / `requirements.txt` — установка окружения и модели.
- `test_voice_media.py` — автотесты.
